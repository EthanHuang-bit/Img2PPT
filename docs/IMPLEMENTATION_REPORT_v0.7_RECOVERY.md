# Img2PPT v0.7.0 Recovery 实施报告

## 恢复背景

此前提供的 v0.7.0 Windows ZIP 位于会话临时工作区，未完成持久保存。工作区自动维护后，该 ZIP 和未提交的 v0.7 源码均被清理；GitHub `main` 只保留 v0.5.1。因此本版本以 GitHub 提交 `8c74089613c2a3bc6191930ebce89e89b6865f00` 为基线，根据会话中保留的功能规格重新实现，不能声称与丢失的 ZIP 字节一致。

## 已恢复能力

- 页面独立分析，最高 20 页并发并保持输出顺序。
- OCR 4 Worker 独占池，避免参数竞争。
- 页面完成即写缓存并返回；前端按完成/总数显示百分比。
- 生成只读缓存，不再调用分析模型。
- 整页视觉失败后四象限并发；8% 交叠、整页低清上下文、全局坐标恢复和对象去重。
- PowerPoint/LibreOffice 渲染、前景感知像素指标、PPTX 可编辑性审计和可选双图模型复核。
- 内容、版式、观感、可编辑性独立门禁与逐页报告。
- 最多 10 次、连续两次无改善停止并保留最佳候选的质量循环编排器。

## 验证证据

- 41 项自动测试通过。
- 故障注入覆盖缺失对象、显著位移、错误颜色、缺失文字、关键数字和不可编辑文字框。
- 真实 HTTP 烟雾测试通过：页面分析写入缓存，生成响应确认 `cacheReused=true`，PPTX ZIP 结构有效，透明文字框和实际字号审计通过。
- 合成测试页被质量门禁标记为“需复核”，证明测试不会因代码路径成功而虚报视觉质量。

## 已知边界

- 没有用户 API Key 时，只能执行本地预检；不会把模拟模型测试冒充真实云模型复核。
- Windows 上真实逐页评分要求 Microsoft PowerPoint 桌面版。未安装时仍生成 PPT，但评分状态为 `not-rendered`。
- 本恢复版仍是工程验证版本，不能据此宣称已达到正式发布质量。
