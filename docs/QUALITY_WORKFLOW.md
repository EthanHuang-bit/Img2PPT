# Img2PPT 质量工作流

## 目标

Img2PPT 的交付目标不是“生成了一个能打开的 PPTX”，而是把输入图片重建成业务用户可继续编辑的 PowerPoint，同时保持内容、排版、视觉层级和语义关系。

质量判断采用四道独立门禁，不能由一个平均分掩盖致命错误：

1. 内容门：缺字、错字、重复文字、关键数字不一致直接失败。
2. 版式与观感门：前景覆盖、边缘、位置、间距、颜色和字体分别测量；大面积白底不参与“抬分”。
3. 可编辑性门：文字必须是透明文本框并实际写入字号；规则对象应为原生形状；图标优先 SVG；整页位图回退直接失败。
4. 模型复核门：模型比较原图和渲染图的图标含义、连接关系、内容完整性和人眼观感。模型不能覆盖前三道硬门禁。

## 测试落地

每个候选版本均执行：

- 代码语法和单元测试。
- 20 页并发、OCR 4 Worker、乱序缓存与缓存复用测试。
- 整页失败后的四分块上下文、坐标恢复、交叠去重测试。
- 故障注入：删除对象、移动对象、修改颜色、删除文字、改变关键数字和整页位图回退。
- 真实 HTTP 流程：上传、逐页分析、缓存、生成、PPTX 审计、渲染和评分。
- 黄金基准：固定输入图片、期望文字清单和可编辑对象要求。

像素路径使用前景掩码、小邻域颜色匹配、边缘容差和背景分离。大模型路径使用结构化 JSON，分别输出内容、版式、观感、语义和关键错误。最终分数由本地确定性指标与模型分数组合，内容和可编辑性采用硬门禁。

## 诊断到开发动作

| 失败类别 | 优先开发对象 |
| --- | --- |
| 缺字、错字、关键数字 | OCR、深色面板二次 OCR、短标签规则、文本模型约束 |
| 位置、间距、边缘 | 边界框、坐标映射、描边外边界、连接器检测 |
| 颜色、字体、抗锯齿 | 颜色采样、字体拟合、小邻域匹配与校准 |
| 图标语义或连接关系 | 视觉模型对象 Schema、图标目录和层级合并 |
| 不可编辑或整页位图 | PPTX 生成策略、媒体关系和结构审计 |

## 迭代停止

一次开发候选可以由多个测试用例验证，但“开发—整体验证”最多 10 次。以下任一条件发生时停止：

- 所有硬门禁与分数门槛均通过；
- 连续两轮没有达到最小有效提升；
- 达到第 10 次。

每轮保留分数更高且未增加硬错误的最佳候选，禁止最后一轮回退覆盖最佳结果。
