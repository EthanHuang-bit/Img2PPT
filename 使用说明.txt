Img2PPT v0.5.1 Windows x64 免安装版
=====================================

运行方法
1. 右键 ZIP 文件，选择“全部解压”。
2. 打开解压后的文件夹。
3. 双击 Start-Img2PPT.cmd。
4. 浏览器会自动打开 Img2PPT 页面。
5. 使用期间请不要关闭启动窗口；关闭窗口即停止工具。

重要说明
- 无需安装 Node.js、Python、OCR 或 PowerPoint。
- 不启用“大模型视觉增强”时，工具完全离线运行，图片不会上传到互联网。
- 可分别配置 OpenAI、Qwen 或自定义视觉模型，以及 DeepSeek、Qwen、OpenAI 或自定义文本模型。
- 启用视觉模型时，图片会发送给您配置的服务商；启用文本模型时，OCR 文字会发送给对应服务商。
- API Key 仅随本次请求使用，不写入磁盘、浏览器存储、日志或导出文件。
- 大模型增强是可选项。未填写 Key 或不开启时，工具自动使用本地 OCR、形状和图标识别。
- 导出的 PPTX 可使用 Microsoft PowerPoint 或兼容软件打开。
- 请勿只从 ZIP 内直接双击启动，必须先完整解压。
- 本版本仅支持 Windows x64。

如果 Windows SmartScreen 弹出提示
- 点击“更多信息”，确认文件名为 Start-Img2PPT.cmd，然后选择“仍要运行”。

常见问题
- 浏览器没有自动打开：手动访问 http://127.0.0.1:4173
- 4173 端口被占用：工具会自动尝试 4174、4175 等后续端口，请查看启动窗口显示的地址。
- 大模型增强失败：先在“设置”中点击对应的“测试”按钮；检查服务商、Base URL、接口类型、API Key 和模型名称。转换失败时会在报告中说明错误并回退到本地识别。
- “测试连接成功”只代表接口、图片输入和 JSON 输出正常。正式页面远比测试图复杂，Qwen 视觉分析通常需要 2–5 分钟，请保持启动窗口和浏览器开启。
- Qwen 正式分析已使用流式响应，最长等待 6 分钟。若仍超时，优先将 Base URL 替换为百炼控制台提供的 Workspace 专属地址。

推荐配置
- Qwen 视觉：服务商选 Qwen，模型 qwen3-vl-plus；请使用与 API Key 地域一致的 Base URL，优先使用 Workspace 专属地址。
- DeepSeek 文本：服务商选 DeepSeek，模型 deepseek-v4-flash。
- DeepSeek 当前只用于 OCR 文本纠错，不能识别图片。
